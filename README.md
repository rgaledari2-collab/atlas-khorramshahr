# اطلس جامع روستاهای محروم محور شلمچه و خرمشهر
### سامانه رصد، مدیریت اطلاعات و محرومیت‌زدایی · جمعیت امام‌رضایی‌ها

اطلس تعاملی و شناختی منطقه مرزی شلمچه و حومه غربی خرمشهر، طراحی‌شده جهت نمایش داده‌های میدانی، پایش وضعیت خانواده‌های کم‌برخوردار و ایتام، ارزیابی زیرساخت‌ها، مدارس و طرح‌های اشتغال‌زایی روستایی.

---

## 🗺️ ویژگی‌های کلیدی سامانه
- **نقشه هوایی ماهواره‌ای با وضوح بالا:** ناوبری و زوم روان، پین‌های راهبردی و یادمان‌های دفاع مقدس (نهر خین، شلمچه، پارکینگ اربعین، مجتمع فاطمه الزهرا).
- **شناسنامه تحلیلی تفصیلی روستاها:** جمعیت، بعد خانوار، هرم سنی، آمار دانش‌آموزان و مدارس، مشخصات توان‌یابان، و اولویت‌های مداخله.
- **سامانه تصمیم‌یار و فیلترهای چندمعیاره:** رتبه‌بندی روستاها، مقایسه تطبیقی شاخص‌ها و جستجوی لحظه‌ای در پرونده‌ها.
- **حفظ حریم خصوصی مددجویان:** ماسک‌گذاری خودکار کدهای ملی و شماره‌های تماس در ظاهر عمومی جدول‌ها.
- **معماری مستقل و فوق‌سریع:** اجرا بر پایه Vanilla SPA بهینه‌سازی‌شده با فشرده‌سازی خودکار Brotli و پشتیبانی از دستگاه‌های با توان پردازش محدود.

---

## 🚀 نحوه اجرا در محیط محلی (Local Development)

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت نسخه نهایی جهت استقرار (Production Build)
npm run build
```

آدرس پیش‌فرض سامانه:  
`http://localhost:3000/`

---

## 🏛️ ساختار مخزن
- `index.html`: هسته اصلی رابط کاربری، استایل‌ها، منطق تعاملی نقشه و پایگاه داده روستاها.
- `public/`: تصاویر ماهواره‌ای بهینه‌سازی‌شده (`.webp`)، داده‌های آماری ساختاریافته (`public/data/*.json`) و نمادهای بصری.
- `vite.config.ts`: پیکربندی محیط بیلد و فشرده‌سازی بروتلی.
- `.github/workflows/deploy.yml`: پایپ‌لاین استقرار خودکار بر روی GitHub Pages.
